# DSH扩展（dsh-extensions）

给 DeepSeek Harness 的设置面板加一个「DSH扩展」分区，把几个小功能收在同一个入口里。

## 功能

| 配置项 | 说明 |
|---|---|
| 全局 AGENTS.md | 直接编辑所有会话都会加载的 `~/.dsh/AGENTS.md`，输入后自动保存 |
| 回答完成通知 | 窗口最小化或不在前台时，回答结束发系统通知；点击通知恢复窗口并打开该会话 |
| 工作区菜单 | 控制工作区右键和「…」菜单里的两个扩展项：「修复沙箱权限」「归档全部会话」；默认开启，关掉后立即消失 |
| 插件兼容性检测 | 对照当前运行的 DSH 检查本扩展的版本要求、bundle 补丁、host/client 入口和前后端路由 |

「修复沙箱权限」「归档全部会话」这两个菜单项不在设置分区里，分别由「工作区菜单」下的两个开关控制是否出现；「归档全部会话」还只在该工作区还有未归档的已有会话时出现。

## 安装

插件管理器 → 添加插件，粘贴下面的地址，装好后重启应用：

```
github:lllcccwww/dsh-extensions
```

本地开发时，也可以直接把仓库目录交给插件管理器（仓库根目录就是插件包）。

## 使用

打开 **设置 → DSH扩展**。

全局 AGENTS.md：在输入框里写偏好即可，停止输入约 0.7 秒后自动保存；输入框右下角显示已用字节数和单条链上限，左下角短暂显示保存状态。改动对新会话生效。

回答完成通知：在「启用通知」子项里开关；「发送测试通知」会立刻弹一条，用来确认系统通知是否正常。

修复沙箱权限：先在设置 → DSH扩展 → 工作区菜单里确认「修复沙箱权限」是开启的，然后在工作区列表右键，或点行尾的「…」，选「修复沙箱权限」。会弹一次 UAC；同意后开一个管理员 PowerShell 窗口，修复直接开始运行，不用再输入任何命令。窗口里最后一行只会是「结果：成功」「结果：部分成功」「结果：失败」之一，后两种把窗口内容发给助手。

它做两件事：先核对整棵树，再一次性把权限下推到根目录以下；只有没继承到的对象才逐个补，最后把整棵树设为低完整性。每个工作区有自己的标识，所以不能拿别的工作区的命令来用。已经修好的工作区几秒钟就核对完；第一次修一个十几万文件的工作区大约半分钟。

归档全部会话：先在设置 → DSH扩展 → 工作区菜单里确认「归档全部会话」是开启的，然后在工作区行右键或点行尾的「…」，选「归档全部会话」。它把该工作区里当前可见、尚未归档的会话一次归档；列表顶部的「新会话」空草稿会保留，不会被归档。没有运行中的会话时直接执行；有会话正在运行时会先确认，确认后会停止这些会话正在进行的回答、后台任务和计划任务，再归档。完成后会提示归档了几个、失败几个。归档是可逆的，在会话列表切到归档筛选后可以逐个取消归档。

插件兼容性检测：打开设置分区时自动跑一次，也可以点「重新检测」。它只检查本扩展，不看其他插件。点击后按钮显示转圈和「正在检测中…」，结束后在按钮旁显示结果图标：通过、需注意或不通过；把鼠标移到图标上可以看当前 DSH 版本、具体原因和提示。检测是只读的，不改插件文件，也不改 DSH 配置。

## 注意

- 通知由页面发出：最小化、隐藏到托盘都可以，**退出应用后不会通知**。
- 系统拒绝通知权限时不会弹出任何通知，「启用通知」的描述里会显示当前权限状态。
- 全局 AGENTS.md 与项目里的 AGENTS.md 会同时注入，项目文件更具体、优先；超过 1 MiB 的文件无法在这个编辑器里保存。
- 「修复沙箱权限」只在 Windows 的菜单和「工作区菜单」子项里出现，由该子项的开关控制；开关只影响菜单项，不改任何权限。它不改文件内容，只补权限项；修复前会把根目录的权限描述备份到临时目录并在窗口里打印路径。
- 「归档全部会话」只处理当前可见的会话，所以访问受限的会话不会被误归档；「新会话」空草稿不参与批量归档，避免归档后导航立即重建一个空会话。空闲会话不会二次确认，只有运行中的会话会弹确认。归档会隐藏会话，不删除会话记录。关掉「工作区菜单」里的这个子项只会隐藏菜单项，不影响已经归档的会话。
- 插件兼容性检测只覆盖版本声明和入口加载，不等于完整的功能回归。本扩展目前没有声明 `engines.dsh`，所以 DSH 不会在启动时拦截版本不匹配；升级后如果报告列出错误，先按提示更新代码或入口，再重启验证。如果升级后整个「DSH扩展」分区没有出现，说明 DSH 已在启动时跳过这个 bundle，检测也打不开；此时先看 DSH 的插件列表或启动日志。

## 卸载

在插件管理器里卸载后重启应用。`~/.dsh/AGENTS.md` 和通知开关的状态都会保留。
